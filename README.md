# BridgeHold

Unity 6000.6.3f1 的竖屏 3D 尸潮防守 MVP。场景、美术模型、音效和对象池由代码生成，不需要外部资源。

## 运行

1. Unity Hub → Add project from disk → 选择本目录。
2. 打开 `Assets/BridgeHold/Scenes/Bridge.unity`；如果尚未生成，使用菜单 **BridgeHold → Create or Open Game Scene**。
3. Game 视图设置 **9:16 / 540 × 960**，按 Play。
4. 在战斗区域按住并左右拖动，角色左右移动并持续沿桥面向前射击；松开停止。手机对应单指拖动。电脑也可用 A/D 或左右方向键移动，同时按住鼠标射击；通过左右移动对准敌人或奖励方块，枪口方向始终与桥面纵向一致。角色只能在桥面内横移；从 UI 按钮开始的拖动不会触发移动或射击。
5. 点击城墙朝向玩家一面的 ICE / FIRE / SHOCK 方块，为当前豌豆枪切换元素加成；同时只有一种生效。点击设施旁的 `+` 消耗防御积分升级，灰色表示不足或已满级。
6. 射击金色奖励箱后，左右弹出两个实体奖励方块，战斗继续。左侧强化枪械，右侧获得积分。连续三枪命中同一个方块即选中；命中另一方块、僵尸或空枪会重置连击计数，停止射击本身不会重置。选中后两个方块同时消失，未选完时不会再生成新箱子。
7. 最底部安全区并排显示两张固定武器卡片：左侧单发豌豆枪、右侧三发豌豆枪。点击哪张就装备哪把，当前卡片绿色高亮；重复点击已装备卡片不会切换。没有轮换按钮或 Q 快捷键。单发每次射出一颗绿色豌豆；三发同时射出三颗、小角度散射，射速为单发的 65%，每颗伤害相同。豌豆飞行命中后结算伤害。切换不暂停、不弹窗，保留冷却与在途豌豆；共享枪械强化与元素。手机支持一指拖动射击、另一指点切换。奖励选择只计中间一颗，仍需三次射击。
8. 左上暂停，或按 Esc；失败/通关可以重开。

## 已实现

- 一整排共享生命值的防御墙；木、石、铁、铜、金五级外观，升级补充耐久；破墙后敌人攻击玩家。
- 两侧炮台独立选敌并自动弧线范围炮击：优先各自一侧、最靠近防线的敌人，有多个敌人时避开另一炮台的目标；仅剩一个敌人时允许集火；破墙后炮台停止、墙面元素块消失，保留破墙前已激活的武器元素。
- 冰豌豆减速、火豌豆提高直接命中伤害（一级 +50%，每级再加 20%）、电豌豆连锁伤害，三系独立五级升级。墙体随元素选择短暂闪亮，并持续显示冰晶、火焰或电弧；破墙时特效消失。枪身、弹丸和命中效果使用激活元素的颜色，单发和三发武器均享受加成；在途豌豆保留发射时的加成。
- 普通僵尸、每三秒群体治疗的白衣医生、3/6/10 波的大型 Boss。
- 10 波递增尸潮、胜负、暂停、重开、命中数字、轨迹、爆炸、音效和轻微震屏。
- 奖励箱有生命值，必须主动射击；二选一不会自动升级防御。
- 初始 40 防御积分，每波补给 10，Boss 额外 20；箱子提供主要积分来源。没有金币系统。
- 300 个敌人池、20 个炮弹池和 140 个效果槽。敌人不使用 Rigidbody、NavMesh 或独立 Update。

## 工程说明

`BridgeHoldGame.cs` 是集中式原型模拟，分为场景构建、池、波次、敌人、武器、炮台、反馈和 UI 方法。为便于开箱运行，暂时采用 Built-in 管线、共享 Standard 材质、程序化模型与 IMGUI。数据与表现后续可拆为 ScriptableObject 和独立组件；生产 UI 应迁移至 Canvas / UI Toolkit。

视觉参考用于构图和配色，并非已经达到参考图的美术完成度。目前模型是可替换的低模占位资源。没有复杂动画、正式关卡平衡、存档和商业化功能。

## 构建

- macOS 原型：菜单 **BridgeHold → Build macOS Prototype**，输出 `Builds/BridgeHold.app`。
- Android / iOS：通过 Unity Hub 给本编辑器安装对应 Build Support，在 Build Profiles 切换平台。默认竖屏；iOS 还需要 Xcode 和签名配置，Android 需要 SDK/NDK。
- 当前开发验证平台是 macOS；尚未在 iOS/Android 真机测量 100–300 单位的帧率。对象池容量不等于性能保证，正式发行前需在目标设备 Profile 并合并环境网格、优化敌人网格/动画和 UI。

## 验证

场景生成与编译：

```sh
Unity -batchmode -nographics -projectPath "$PWD" -executeMethod BridgeHold.Editor.BridgeHoldSetup.CreateScene -quit -logFile /tmp/bridgehold-compile.log
```

运行核心循环冒烟检查（不要附加 `-quit`，测试自行退出）：

```sh
Unity -batchmode -nographics -projectPath "$PWD" -executeMethod BridgeHold.Editor.BridgeHoldSmoke.Run -logFile /tmp/bridgehold-smoke.log
```

检查覆盖场景启动、池容量、波次生成、防御墙承伤、破墙、玩家受伤、击杀回收、射击箱子、暂停/恢复、最终波胜利与重置。
