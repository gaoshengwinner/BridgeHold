# 验证记录

Unity 6000.6.3f1 / macOS / Apple Silicon。

Play Mode 冒烟检查的 12 项断言已通过，完整输出见 `unity-smoke.log`：场景启动、300 敌人池、重置生命值、波次生成、墙优先承伤、整墙破坏、玩家受伤、敌人回收与击杀计数、射击奖励箱、暂停、恢复、最后一波胜利。

Unity 编辑器自身的 SearchDatabase 索引初始化在批处理日志中产生 `ArgumentOutOfRangeException`；不属于游戏代码，未阻止测试完成。游戏逻辑检查以 `BRIDGEHOLD_SMOKE_OK` 结束。

独立 macOS 构建曾发现 Standard Shader 被裁剪，已通过 Resources 材质资产修复。已在独立窗口确认场景、设施与 UI 正常显示。随后调整主角位置与镜头，避免主角被底部状态栏遮挡。

尚未验证：iOS/Android 真机帧率、触摸手感、不同屏幕安全区、10 波通关难度与完整数值平衡。

最终构建在临时副本 `/tmp/BridgeHoldVerification` 中完成，以避免占用正在打开的工作工程；完整构建输出见 `unity-build.log`。最终 macOS 包的启动检查见 `player-startup.log`。

## 左右移动改动

新增战斗区域拖动横移并射击、A/D 和左右方向键横移、桥面边界限制、暂停/奖励选择后的手势清理、重开时回中，以及破墙后僵尸横向追击。

`unity-movement-smoke.log` 中 17 项检查通过，其中新增横向移动不改变纵向位置、左右边界、暂停禁止移动和重开回中检查。此轮修改针对 Unity 工程，先前 macOS 试玩包未重新构建；手机触摸手感仍需真机确认。

## 实体奖励方块（三枪选择）

取消奖励弹窗和奖励暂停状态。箱子击破后，桥面左右出现可射击方块，分别提供武器成长和防御积分；保持战斗与操作持续运行。连续三枪命中同一方块才结算，换目标或打空会重置计数；只结算一项奖励，并同时隐藏两个方块。待选择期间不会生成新箱子，奖励数值在箱子破坏时固定。

`unity-reward-smoke.log` 的 25 项断言通过，包含不中断战斗、两枪不结算、切换/打空重置、左右奖励分别结算、只发奖一次和重开清理。此轮更新 Unity 工程，未重建旧 macOS 试玩包。

## 双炮台独立选敌

左右炮台优先选择各自一侧、最靠近防线的敌人，有其他存活敌人时避开另一门炮的目标；只剩一个目标时允许集火。每门炮分别记录目标、转向和炮弹落点，击杀与重开时清理目标引用。

`unity-turret-smoke.log` 的 33 项检查通过，新增覆盖两侧独立目标、不同落点、跨侧补位、单目标集火、无敌人不选目标及重置清理。临时验证工程已删除。Unity 工程已更新，iOS 导出和旧桌面包未重新构建。

## 战斗中切换武器

底部已有状态栏加入步枪 / 重炮切换，支持 Q 和触摸第二指点击。无弹窗、无暂停，当前射击冷却保留；两把武器共享强化和元素。重炮为慢速高伤单体武器，伤害为步枪的 3.5 倍，射速为 1/4，模型和音效随装备改变。

`unity-weapon-smoke.log` 中 41 项检查通过，包含战斗状态、移动、模型同步、重炮伤害、冷却保留、暂停禁止切换、强化保留与重开恢复。手机多指触摸手感仍需真机验证。

macOS 试玩版已构建至 `Builds/BridgeHold-WeaponPreview.app`，构建日志见 `unity-weapon-build.log`。已在独立窗口确认底部布局、Q 切换、武器模型与状态文字同步，战斗持续运行。iOS 导出未更新。

## 底部卡片与豌豆枪

武器卡片贴近屏幕底部安全区（8 个 UI 单位边距），删除卡片下方的操作提示。武器替换为单发豌豆枪和三发豌豆枪，绿色单管 / 三管模型；120 个复用豌豆槽，球形弹丸实际飞行并在命中时造成伤害。三发每次同时射出三颗，轻微散射，射速为单发的 65%。奖励选择只计中央豌豆，每次射击至多计一次，仍需三次命中。

`unity-pea-smoke.log` 的 50 项检查通过，包括一颗 / 三颗生成、命中前不扣血、三颗分别结算、飞行移动、切枪保留弹丸、重开回收和三发奖励计数。macOS 构建成功，输出 `Builds/BridgeHold-PeaPreview.app`，日志见 `unity-pea-build.log`。iOS 导出未更新，手机触摸仍待真机验证。

## 双枪卡片与墙面元素加成

底部同时显示两张固定枪卡，点击直接装备对应武器，重复点击不切走；取消 SWAP 轮换按钮和 Q。生命条位于双卡片上方。ICE / FIRE / SHOCK 实体块附着于城墙朝向玩家的一面，当前元素点亮，枪身和豌豆使用对应颜色。

冰弹减速；火弹一级直接伤害 +50%，每升一级再加 20%；电弹命中后连锁附近敌人。单发、三发均继承激活元素，在途豌豆保留发射时的伤害和元素等级。破墙后元素块随墙消失，保留最后激活的元素。

`unity-elements-smoke.log` 中 60 项检查通过，新增直接卡片选择、重复点击、双卡片不重叠、墙面挂载、冰减速、火弹及三发火弹增伤、电连锁与在途元素保留。手机触摸与屏幕安全区仍需真机确认。

## 墙体元素特效

ICE 在墙顶生成轻微闪动的冰晶，FIRE 显示跳动火苗，SHOCK 显示锯齿电弧；切换元素时墙面产生 0.9 秒的对应颜色闪光，随后保留轻量常驻效果。所有特效复用固定对象，贴近墙顶，不占用伤害反馈效果池；随破墙隐藏，升级保留，重开恢复冰效果。

`unity-wallfx-smoke.log` 中 67 项检查通过，包含各元素效果互斥、切换闪光、闪光消退后保留常驻效果、破墙隐藏与重开恢复。桌面预览使用独立应用标识以避免与旧试玩窗口混淆。
